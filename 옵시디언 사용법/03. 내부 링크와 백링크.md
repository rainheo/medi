# 내부 링크와 백링크

옵시디언의 핵심 기능입니다. 노트 간 연결을 통해 지식을 그물처럼 엮을 수 있습니다.

## 내부 링크 만들기

이중 대괄호 `[[ ]]`를 사용하면 다른 노트로 연결되는 링크가 생성됩니다.

```
[[노트 이름]]
[[노트 이름|표시할 텍스트]]
[[폴더/노트 이름]]
```

### 특정 헤딩으로 링크

```
[[노트 이름#헤딩 이름]]
[[노트 이름#헤딩 이름|표시 텍스트]]
```

### 특정 블록으로 링크

블록 ID를 사용해 문단 단위로 링크할 수 있습니다.

```
[[노트 이름^블록ID]]
```

## 백링크(Backlinks)

백링크는 **현재 노트를 참조하는 다른 노트들의 목록**입니다.

- 오른쪽 사이드바에서 확인 가능
- 연결된 언급(Linked mentions)과 비연결 언급(Unlinked mentions) 표시
- 어떤 노트가 이 노트를 인용하는지 파악 가능

## 그래프 뷰

`Ctrl+G`로 모든 노트의 연결 관계를 시각적으로 확인합니다.

- **점(Node)**: 개별 노트
- **선(Edge)**: 노트 간 링크
- 링크가 많은 노트일수록 크게 표시됨

### 로컬 그래프

현재 노트와 직접 연결된 노트만 보여줍니다.
- 명령 팔레트(`Ctrl+P`) → "로컬 그래프 열기" 검색

## 노트 임베드

링크 앞에 `!`를 붙이면 다른 노트의 내용을 현재 노트에 삽입할 수 있습니다.

```
![[노트 이름]]
![[노트 이름#헤딩]]
```

## 미완성 링크 (Orphan Notes)

아직 존재하지 않는 노트로 링크를 만들면 나중에 해당 노트를 만들 때 자동으로 연결됩니다. 이를 활용해 아이디어를 미리 연결해 둘 수 있습니다.
