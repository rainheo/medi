# 옵시디언 시작하기

옵시디언(Obsidian)은 로컬에 저장된 마크다운 파일을 기반으로 하는 강력한 지식 관리 도구입니다.

## 옵시디언이란?

- **로컬 우선**: 모든 노트는 내 컴퓨터에 `.md` 파일로 저장됩니다.
- **연결된 사고**: 노트 간 링크를 통해 지식을 네트워크처럼 구성합니다.
- **플러그인 생태계**: 수백 개의 커뮤니티 플러그인으로 기능을 확장할 수 있습니다.

## 볼트(Vault) 개념

볼트는 옵시디언이 관리하는 폴더입니다. 모든 노트와 설정이 이 안에 저장됩니다.

1. 옵시디언 실행 후 **볼트 열기** 클릭
2. 기존 폴더를 볼트로 지정하거나 새 폴더 생성
3. 볼트 내 모든 `.md` 파일이 자동으로 노트로 인식됨

## 기본 인터페이스

| 영역 | 설명 |
|------|------|
| 왼쪽 사이드바 | 파일 탐색기, 검색, 태그 등 |
| 편집 영역 | 노트 작성 및 읽기 |
| 오른쪽 사이드바 | 아웃라인, 백링크, 속성 등 |
| 명령 팔레트 | `Ctrl+P`로 모든 기능에 빠르게 접근 |

## 첫 번째 노트 만들기

1. `Ctrl+N` 으로 새 노트 생성
2. 제목 입력 후 내용 작성
3. `Ctrl+S` 로 저장 (자동 저장도 지원)
