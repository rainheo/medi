# 태그와 폴더 구조

옵시디언에서 노트를 체계적으로 정리하는 두 가지 방법입니다.

## 태그

태그는 노트를 유연하게 분류하는 방법입니다. 폴더와 달리 하나의 노트가 여러 태그를 가질 수 있습니다.

### 태그 사용법

본문 내 어디서나 `#태그명` 형식으로 작성합니다.

```
#아이디어 #개발 #독서메모
```

### 중첩 태그

슬래시(`/`)를 사용해 계층적 태그를 만들 수 있습니다.

```
#개발/파이썬
#개발/자바스크립트
#독서/기술서적
```

### 프론트매터(Frontmatter) 태그

노트 상단에 YAML 형식으로 태그를 지정할 수 있습니다.

```yaml
---
tags:
  - 아이디어
  - 프로젝트
created: 2026-03-10
---
```

### 태그 패널

왼쪽 사이드바의 태그 패널에서 모든 태그와 사용 횟수를 확인하고 클릭으로 필터링할 수 있습니다.

## 폴더 구조

폴더는 노트를 물리적으로 분리하는 전통적인 방법입니다.

### 폴더 생성

- 파일 탐색기에서 우클릭 → 새 폴더
- 폴더 내 노트는 `[[폴더명/노트명]]` 형식으로 링크

### 추천 폴더 구조 예시

**PARA 방법론 기반:**
```
📁 1. Projects    (현재 진행 중인 프로젝트)
📁 2. Areas       (지속적으로 관리하는 영역)
📁 3. Resources   (참고 자료 및 지식)
📁 4. Archive     (완료되거나 비활성 항목)
```

**Zettelkasten 기반:**
```
📁 Inbox          (빠르게 캡처한 메모)
📁 Notes          (정제된 영구 노트)
📁 References     (외부 자료 정리)
📁 Templates      (노트 템플릿)
```

## 태그 vs 폴더

| 기준 | 태그 | 폴더 |
|------|------|------|
| 다중 분류 | 가능 | 불가능 |
| 계층 구조 | 제한적 | 자유로움 |
| 검색 | 빠름 | 보통 |
| 시각적 구성 | 약함 | 강함 |

> 태그와 폴더를 함께 사용하는 것이 가장 효과적입니다.

## 검색 활용

`Ctrl+F`: 현재 파일 내 검색
`Ctrl+Shift+F`: 전체 볼트 검색

검색 시 태그로 필터링:
```
tag:#개발
tag:#개발/파이썬
```
