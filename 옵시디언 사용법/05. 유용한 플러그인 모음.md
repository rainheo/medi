# 유용한 플러그인 모음

옵시디언은 플러그인으로 기능을 크게 확장할 수 있습니다. 설정 → 커뮤니티 플러그인에서 설치합니다.

## 플러그인 설치 방법

1. `Ctrl+,` → **커뮤니티 플러그인** 클릭
2. **커뮤니티 플러그인 탐색** 버튼 클릭
3. 플러그인 검색 후 **설치** → **활성화**

> 처음 사용 시 "안전 모드 끄기"를 해야 커뮤니티 플러그인을 사용할 수 있습니다.

---

## 필수 플러그인

### Dataview
노트를 데이터베이스처럼 쿼리하고 동적 목록을 생성합니다.

```dataview
TABLE file.ctime AS "생성일"
FROM #프로젝트
SORT file.ctime DESC
```

### Templater
강력한 템플릿 기능을 제공합니다. 날짜, 파일명 등을 자동으로 삽입할 수 있습니다.

```
# {{tp.file.title}}

생성일: {{tp.date.now("YYYY-MM-DD")}}
```

### Calendar
일별 노트(Daily Note)를 캘린더 형식으로 관리합니다.

### Kanban
칸반 보드를 만들어 프로젝트 진행 상황을 시각적으로 관리합니다.

---

## 글쓰기 편의 플러그인

### Outliner
계층형 목록을 더 쉽게 편집하고 접고 펼칠 수 있습니다.

### Natural Language Dates
`@today`, `@tomorrow`, `@next week` 같은 자연어로 날짜를 입력합니다.

### Linter
마크다운 문법을 자동으로 정리하고 일관성을 유지합니다.

---

## 시각화 플러그인

### Excalidraw
옵시디언 내에서 손그림 스타일의 다이어그램을 그릴 수 있습니다.

### Mind Map
현재 노트의 헤딩 구조를 마인드맵으로 시각화합니다.

---

## 생산성 플러그인

### Tasks
강력한 할 일 관리 기능을 제공합니다. 마감일, 반복, 우선순위 설정이 가능합니다.

```
- [ ] 보고서 작성 📅 2026-03-15 🔁 every week
```

### QuickAdd
자주 사용하는 작업을 매크로로 등록해 빠르게 실행합니다.

### Periodic Notes
일간/주간/월간/연간 노트를 체계적으로 관리합니다.

---

## 핵심 플러그인 (기본 내장)

설정 → 핵심 플러그인에서 활성화할 수 있는 내장 기능들:

| 플러그인 | 기능 |
|---------|------|
| 일별 노트 | 날짜별 일기/저널 |
| 슬라이드 | 노트를 프레젠테이션으로 변환 |
| 워크스페이스 | 창 배치 저장 및 불러오기 |
| 단어 수 | 실시간 글자/단어 수 표시 |
| 오디오 레코더 | 음성 메모 녹음 |
